# Landing Pages

Threadsプロフィールから飛ばすペライチ案です。現時点ではアフィリエイトリンクをプレースホルダーにしています。

## Files

- `fortune.html`: 占いアカウント用
- `side-hustle.html`: 副業アカウント用

## Link Replacement

リンク取得後、各HTML内の次の文字列を実リンクに差し替えます。

- `AFFILIATE_LINK_FORTUNE_MAIN`
- `AFFILIATE_LINK_FORTUNE_SUB_1`
- `AFFILIATE_LINK_FORTUNE_SUB_2`
- `AFFILIATE_LINK_SIDE_WORK`
- `AFFILIATE_LINK_SIDE_AI`
- `AFFILIATE_LINK_SIDE_LEARNING`

## Publishing

公開先は後で決めて大丈夫です。候補は以下です。

- Vercel
- Cloudflare Pages
- GitHub Pages
- 既存ドメイン配下

公開URLが決まったら、Threadsのプロフィールリンクに設定します。
