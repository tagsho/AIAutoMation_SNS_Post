# Goal: Rakuten Affiliate Integration

Set the side-hustle Threads account up to test a low-friction Rakuten affiliate track without breaking the existing high-ticket Deeps funnel.

## Why

The side-hustle account has a thin posting history because the GitHub secret for `THREADS_SIDE_HUSTLE_TOKEN` was expired until 2026-05-25.

Now that publishing is working again, use the next week to test two monetization paths:

- High-ticket: Deeps SNS/AI/adult-adjacent education offers.
- Low-friction: Rakuten-style work environment, lifestyle, and time-saving goods.

Rakuten is not expected to beat Deeps on single-sale reward. Its role is to create safer everyday content, more natural note articles, and product-selection posts that can be repeated.

## Implementation

- Add `rakuten_workstyle` as a side-hustle content pillar.
- Keep side-hustle posting at 4 posts per day.
- Keep link frequency at roughly 1 CTA per 6 generated posts.
- Use the existing side-hustle note link as the temporary `rakuten_note` destination.
- Replace `rakuten_note` with a dedicated Rakuten note once product links are ready.

## Rakuten Track Positioning

Account angle:

> AIで副業を続ける人の作業環境、生活効率化、投稿環境づくり。

Recommended product categories:

- Desk work: chair cushions, monitor stands, desk lights, keyboards, mice.
- AI workflow: second monitors, laptop stands, noise reduction, timers.
- Side-hustle continuation: notebooks, storage, fatigue reduction, small desk gear.
- Time-saving life goods: cleaning, kitchen, laundry, one-person living storage.

## Posting Rules

Use:

- "悩み -> 選び方 -> 比較 -> 注意点 -> リンク"
- "在宅ワークで肩がつらい人"
- "机が狭くて集中できない人"
- "副業を続けるために作業環境を整える"

Avoid:

- "放置で稼げる"
- "AIだけで自動収益"
- "絶対買うべき"
- "これ一択"
- DM誘導
- 楽天以外の短縮URL
